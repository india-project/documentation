**Build the minimum public surface area:**

  - [ ] Mission  
  - [ ] How it works  
  - [ ] Email signup  
  - [ ] “Request a pathway” form (no promises)

  - [ ] 10 starter playbooks (short, useful, realistic)

  - [ ] Record 3 episodes before launch (to build momentum)

## Phase 2 (4–8 weeks): MVP Accounts & First Experiment Cohort

**Expand with user functionality:**

- [ ] Add user accounts (only when there’s something meaningful for users)  
  - [ ] Account role: Learner  
  - [ ] Account role: Mentor  
  - [ ] Account role: Equipment donor  
  - [ ] Account role: Partner organisation
- [ ] Pathways page  
  - [ ] Users can select Job track  
  - [ ] Users can select Micro-business track  
  - [ ] Users can select Digital basics track
- [ ] Run a tightly scoped cohort:  
  - [ ] ~20 people, 4 weeks  
  - [ ] One measurable outcome per person  
      - [ ] (e.g. CV done, first invoice sent, first portfolio published, etc.)

---

## Phase 3 (2–6 months): Partnerships & Repeatable Playbook Machine

**Move beyond hobby stage:**

- [ ] Partner with 1–3 trusted local organisations  
  - [ ] Partners assist with participant selection and local context
- [ ] Build a repeatable content pipeline:  
  - [ ] Every podcast episode creates:  
    - [ ] Summary  
    - [ ] Checklist  
    - [ ] Template  
    - [ ] Translated version
- [ ] Add lightweight verification and safety:  
  - [ ] Scam reporting  
  - [ ] Moderation  
  - [ ] Code of conduct  
  - [ ] Privacy-first defaults

---

## Phase 4 (6–18 months): Scaling with Integrity

**Scale with mechanisms that preserve dignity:**

- [ ] Equipment refurb pipeline  
  - [ ] Transparent, fair selection process
- [ ] Micro-grants  
  - [ ] Tied to completion of learning sprints (not pity-based giveaways)
- [ ] Open source "starter kits" by pathway  
  - [ ] Like a GitHub repo, but for life/tooling
